# Anchor Portal

Personal journal, tasks, and calendar-linked reminders.

Mobile-first Progressive Web App. Install on iPhone via Safari → Share → Add to Home Screen.

## Features (v0.1)
- **Journal**: dated free-form entries
- **Tasks**: priority, due dates, lists/projects, check-off
- **Calendar**: month view + day detail with reminders, tasks & journal linked to dates
- Offline / on-device storage (localStorage)
- Clean dark UI optimized for phone

## Live
Once GitHub Pages is enabled: https://greg3421.github.io/anchor-portal/

## How to install on iPhone
1. Open the site in Safari
2. Tap the Share button
3. Scroll and tap "Add to Home Screen"
4. It will appear like a native app

Data stays on your device for now.
